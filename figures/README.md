# Figures manuscript repository
This repository accompanies the figures featured in the publication titled: "Bacterial cell-free DNA profiling reveals co-elevation of multiple bacteria in newborn foals with suspected sepsis".

Data and statistical analyses were performed using Python (v3.10) with the packages NumPy (v1.26.0) and Statannotations (v0.6.0), along with GraphPad Prism (v10.3.0). 
Figures were generated using R (v4.2.0) and Python (v3.10) with the packages Seaborn (v0.11.2) and Pandas (v1.5.3).
